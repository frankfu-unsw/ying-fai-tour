Sources for the three pages. `python3 build.py` puts the shared runtime (`common.js.html`) into each `*.src.html` and
writes `index.html`, `block-a.html` and `block-b.html` one level up. `tools/footprint.py` traced the tower outlines from
the HA floor plans; `tools/estate.js` and `tools/estate_geo.json` are the estate module and its data as they went into
`common.js.html`.
